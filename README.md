# Сервис выдачи книг в библиотеке

Веб-сервис для учёта выдачи книг: выдаёт экземпляр читателю, принимает возврат, считает просрочку
и штраф, показывает сводку по всем выдачам. Учебный сервис курсовой работы по дисциплине
«Оптимизация клиент-серверных приложений».

## Требования

- Python 3.11;
- Docker Desktop с Docker Compose;
- браузер для интерфейса.

Версии библиотек зафиксированы в `requirements.txt`: FastAPI 0.143.0, uvicorn 0.54.0, psycopg 3.2.9.

## Установка и запуск

Команды для Windows PowerShell, выполняются по порядку из корня репозитория.

    git clone https://github.com/Viterok-Andrey/andrey_viter-library.git
    cd andrey_viter-library
    copy .env.example .env
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    docker compose up -d
    python -m scripts.init_db
    python seed.py small
    python -m uvicorn app.main:app --port 8080

## Проверка работоспособности

Интерфейс открывается по адресу http://localhost:8080. Учётная запись для входа — `demo` / `demo`.
После входа виден список выдач; вкладка «Сводка» показывает итоговые показатели, а вкладка
«Выдать / принять» — операции выдачи и возврата. Описание интерфейса программирования
в формате OpenAPI доступно по адресу http://localhost:8080/docs.

## Замеры времени ответа

Сервис должен быть запущен, а в базе загружено нужное наполнение. Замеры снимаются одной командой
для каждого объёма, затем печатаются сводные таблицы:

    python seed.py small
    python -m bench.run small
    python seed.py work
    python -m bench.run work
    python -m bench.report

Серия: прогрев 5 запросов (в расчёт не входит), затем 40 повторов каждой операции; запросы идут
последовательно под учётной записью `APP_USER`. Результаты сохраняются в `bench/results/`.
Процентили считаются методом ближайшего ранга. Число запросов к базе, время в базе и время
открытия соединения сервис сообщает в заголовках ответа `X-DB-Queries`, `X-DB-Time-Ms`
и `X-DB-Connect-Ms`.

## Программный интерфейс

| Метод и путь                | Параметры                     | Ответ                                   |Ошибки             |
|-----------------------------|-------------------------------|-----------------------------------------|--------------------|
| POST /api/login             | username, password (тело)     | 200, {"token": "..."}                   | 401, 422           |
| GET /api/loans              | page, size, status, reader_id | 200, {"items": [...], "total": N}       | 401, 422           |
| GET /api/loans/{id}         | id (в пути)                   | 200, карточка выдачи                    | 401, 404, 422      |
| POST /api/loans             | reader_id, copy_id (тело)     | 201, карточка выдачи                    | 401, 404, 409, 422 |
| POST /api/loans/{id}/return | id (в пути)                   | 200, карточка выдачи                    | 401, 404, 409, 422 |
| GET /api/summary            | —                             | 200, {"on_hands": N, "overdue": M, ...} | 401                |

Коды ошибок: 401 — нет или неверный токен (для входа — неверные логин или пароль); 404 — читатель,
экземпляр или выдача не найдены; 409 — нарушено бизнес-правило; 422 — неверные параметры или тело запроса.

**Элемент списка** (`items`): `id`, `status`, `reader_name`, `book_title`, `inventory_number`,
`issued_at`, `due_date`, `returned_at`, `fine`.

**Карточка выдачи**: `id`, `status`, `issued_at`, `due_date`, `returned_at`, `fine`, а также вложенные
`reader` (`id`, `full_name`, `card_number`), `copy` (`id`, `inventory_number`) и
`book` (`id`, `title`, `author`).

**Сводка**: `on_hands` — сколько экземпляров на руках, `overdue` — сколько из них просрочено,
`top_books` — десять самых востребованных книг (`book_id`, `title`, `author`, `loans_count`).

Поле `status`: `on_hands` — экземпляр на руках в срок, `overdue` — на руках, срок возврата прошёл,
`returned` — возвращён. Даты передаются строками `ГГГГ-ММ-ДД`.

Бизнес-правила:

- срок возврата — 14 дней со дня выдачи;
- просрочка — число дней между сроком возврата и фактической датой возврата;
- штраф — 10 рублей за каждый день просрочки; при возврате он записывается в выдачу, а для
  невозвращённой выдачи в поле `fine` показывается штраф, начисленный на сегодняшнюю дату;
- выдача отклоняется с кодом 409, если экземпляр уже на руках или у читателя есть просроченная выдача;
- возврат уже закрытой выдачи отклоняется с кодом 409.
